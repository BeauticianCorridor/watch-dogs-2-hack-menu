## 🧩 About

**Watch Dogs 2 Companion** is a curated list of Watch Dogs 2 open-source tools:

- **Overlays** — on-screen helpers, layout notes, minimap markers, objective tracker
- **Quality-of-Life Helpers** — inventory organizer, skill tree notes, overlay notes
- **Research Notes** — mission layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Player Helpers
- Objective Tracker — mark missions and side ops
- Minimap Markers — highlight points of interest
- Inventory Notes — organize weapons and gadgets
- Fast Travel Helper — quick access to discovered locations

### 🎨 Visual & Interface
- HUD Customizer — move or hide HUD elements
- Marker Colors — change objective and enemy colors
- Photo Mode Notes — camera and filter presets

### 🏋️ Exploration Layout
- Collectible Map — note locations of key items
- Skill Tree Planner — plan unlocks without respec
- Drone Range Notes — visualize drone signal range
